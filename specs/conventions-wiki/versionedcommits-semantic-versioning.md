# versionedcommits & Semantic Versioning

Use free-form maintainer prose with explicit `@major`, `@minor`, or `@patch`
release metadata. Internal-only changes may omit hints. Read the
[canonical conventions](../../CONVENTIONS.md#versionedcommits--semantic-versioning)
and [agent reference](../../skills/commit-message/REFERENCE.md).
